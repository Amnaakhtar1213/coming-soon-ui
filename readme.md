## COMING-SOON UI 🎇

This project is a common “Coming Soon” interface often used by websites and apps before launching new features.
It is built with **HTML**, **CSS** , featuring:

- Responsive design using @media queries

- Animations with @keyframes

- A custom background with animated blobs made by myself.

------------------------

## Features 👀

- Animated blobs background
- Search input where you give you gmail
- A glow button when you hover over it
- A success msg box that appears when you submit your gmail;

-------------------------------------

## Technologies 🛠️

1. **HTML**
2. **CSS**
3. @media (for responsiveness)
4. @keyframes (for animations)
